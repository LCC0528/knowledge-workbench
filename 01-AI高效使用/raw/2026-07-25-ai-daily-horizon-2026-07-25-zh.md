## [安防摄像头在登录页面内置了 GitHub 管理员 token](https://hhh.hn/hanwha-github-token/) ⭐️ 9.0/10

近日发现一款安防摄像头在其登录页面源代码中硬编码了一个 GitHub 管理员 token，若该 token 处于激活状态，将造成严重的安全威胁。 这一事件凸显了 IoT 设备制造中严重的安全疏忽，可能允许攻击者访问敏感的 GitHub 仓库，进而危及软件供应链安全。 该 token 被嵌入在登录页面的 HTML 中，且具有管理员权限，意味着可以完全访问 GitHub 仓库。token 的泄露可能导致未经授权的代码修改或数据泄露。

hackernews · hhh · 7月24日 11:54 · [社区讨论](https://news.ycombinator.com/item?id=49034292)

**背景**: IoT 设备常常存在不良的安全实践，例如硬编码凭证。将特权 token 嵌入客户端代码是一种已知的漏洞，因为任何人都可以通过查看页面源码轻松提取。此次事件尤为严重，因为该 token 是 GitHub 管理员 token，能够对公司代码仓库进行高级别访问。

**社区讨论**: 评论者对这些糟糕的安全实践表示震惊，有人建议将摄像头放在单独的 VLAN 上并限制互联网访问。其他人则指出其他设备也存在类似问题，例如 OBD-II 诊断仪共享相同的 MAC 地址，凸显了行业内广泛的安全忽视现象。

**标签**: `#security`, `#vulnerability`, `#IoT`, `#supply-chain`, `#credentials`

## [英伟达、微软、Meta 警告不要过度监管开源权重 AI 模型](https://www.cnbc.com/2026/07/24/nvidia-microsoft-meta-open-weight-ai-models.html) ⭐️ 8.0/10

在一封联合公开信中，英伟达、微软和 Meta 警告美国政策制定者不要过度监管开源权重 AI 模型，认为过度限制将损害美国在开源 AI 领域的领先地位。 这封信代表了主要科技公司对限制性 AI 监管的协调立场，凸显了开源与闭源方法之间的持续争论。其结果可能影响美国 AI 政策，并影响全球竞争，尤其是在中国开源权重 AI 日益受到关注的情况下。 这封信专门针对开放权重模型，这类模型允许开发者微调和适配预训练模型。这与 OpenAI 和 Anthropic 等公司的封闭模型形成对比，后者曾主张加强监管。

hackernews · louiereederson · 7月24日 13:32 · [社区讨论](https://news.ycombinator.com/item?id=49035303)

**背景**: 开放权重 AI 模型是指将训练好的参数（权重）公开发布，允许定制和研究的模型。AI 监管的争论往往将开源倡导者（主张创新和透明度）与对滥用的安全担忧对立起来。近期，像 DeepSeek 等中国开源权重模型越来越受欢迎，加剧了美国的竞争和监管讨论。

**社区讨论**: 评论者指出，Anthropic 向支持监管的政治协议捐赠 4000 万美元具有讽刺意味，而英伟达、微软和 Meta 则反对监管。一些人将这种情况与 SOPA 抗议活动相比，认为开源社区已被有效动员。其他人则质疑这封联合公开信背后的动机，考虑到各公司不同的商业模式。
