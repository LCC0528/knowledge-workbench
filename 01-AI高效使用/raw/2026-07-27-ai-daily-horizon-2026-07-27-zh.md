## [美国公民因 GrapheneOS 手机在边境搜查中自动擦除被起诉](https://www.techspot.com/news/113236-us-prosecutors-charge-atlanta-man-after-grapheneos-phone.html) ⭐️ 9.0/10

## [LLM 使形式化验证变得廉价](https://www.imperialviolet.org/2026/07/26/zstd-lean.html) ⭐️ 9.0/10

大型语言模型现在可以自动生成 Lean 语言中的形式化证明，将形式化验证的成本从常规开发的 20 倍降低到大致相当的水平。 这一突破使得形式化验证在日常软件开发中变得可行，有望消除整类漏洞和安全隐患。 该方法使用 LLM 生成证明脚本，再由 Lean 定理证明器验证。作者指出，已验证的汇编代码已经可以通过 Fiat Crypto 和 CryptOpt 等工具生成。

hackernews · zdw · 7月26日 20:53 · [社区讨论](https://news.ycombinator.com/item?id=49062291)

**背景**: 形式化验证通过数学方式证明软件满足其规范，但历史上成本比常规开发高出 20 倍。Lean 是一种交互式定理证明器，能够检查这些证明，而 LLM 现在可以自动生成证明脚本，大幅降低了门槛。

## [PDF 介绍数据导向设计原则](https://www.gamedevs.org/uploads/introduction-to-data-oriented-design.pdf) ⭐️ 8.0/10

Mike Acton 的一篇 PDF 演示文稿介绍了数据导向设计（DoD），提倡通过首先定义数据布局来设计算法，以优化 CPU 缓存使用和性能。 这种范式对于游戏引擎和系统编程等性能关键型软件至关重要，它直接解决缓存效率和内存访问模式问题，从而带来显著的性能提升。 该 PDF 托管在 gamedevs.org 上，参与度高达 160 分，并有 41 条评论，表明社区对数据导向设计用于性能优化的浓厚兴趣。

hackernews · tosh · 7月26日 18:11 · [社区讨论](https://news.ycombinator.com/item?id=49060724)

**背景**: 数据导向设计是一种优化方法，关注数据在内存中的布局和变换方式，优先考虑高效的 CPU 缓存利用。它不同于面向对象设计，后者常常将相关数据分散在堆中。该技术广泛应用于游戏开发中，以实现高帧率和流畅性能。

## [Token 转售市场助长欺诈与转卖](https://vectoral.com/blog/token-relay-market) ⭐️ 8.0/10

Vectoral 发布的新分析揭露，AI token 的转售市场正在助长转卖者和欺诈者利用定价套利，老练的参与者通过滥用计费系统、盗用账户等方式出售打折推理服务。 这个问题威胁到 AI/ML 平台的经济模式，因为 token 欺诈和转卖削弱了定价模型，并使利用免费积分或被盗 token 的企业获得不公平竞争优势。它还揭示了订阅和积分经济中的系统性缺陷。 这个转售市场的运作方式类似于广告欺诈市场，利用被盗账户和金融工具以低于市场的价格获取 token。来自 AWS、Azure 等云服务商的免费积分是廉价 token 的常见来源，有些转卖者能够以实际成本 4%的价格出售。

hackernews · mlenhard · 7月26日 15:17 · [社区讨论](https://news.ycombinator.com/item?id=49058993)

**背景**: Token 转售市场是指 AI 推理 token（用于支付模型使用费用）的二级市场，通常通过灰色市场活动进行买卖。这些市场利用定价差异、促销积分和计费漏洞提供折扣访问。与区块链上的 Relay Token（自动化做市商）不同，这里的转售市场是由人驱动的套利网络，通过转售 token 获利。

## [折扣 LLM 代币中继市场揭露欺诈生态系统](https://simonwillison.net/2026/Jul/26/relay-market/#atom-everything) ⭐️ 8.0/10

Matt Lenhard 的一项调查揭示了一个活跃的市场，通过聚合 API 密钥以折扣价转售 LLM 代币，利用免费试用、被盗凭证和退款攻击等手段。 这一生态系统破坏了 API 安全并扭曲了 AI 经济学，给 LLM 提供商带来财务风险，同时也引起了部署 AI 应用的开发者的担忧。 转售商主要在中国运营，使用 one-api 和 new-api 等开源代理软件聚合凭证，提供更便宜的访问，通常还能绕过地理限制。

rss · Simon Willison · 7月26日 19:30

**背景**: LLM API 提供商（如 OpenAI 和 Anthropic）按 token 使用量收费。中继市场通过聚合多个 API 密钥——有些是通过滥用免费试用获得的，有些是盗取的——并通过负载均衡请求的代理服务器提供这些密钥，从而利用这些定价模式。one-api 和 new-api 等开源项目虽然是合法的 API 网关，但可能被滥用于欺诈目的，从而助长了这一做法。
