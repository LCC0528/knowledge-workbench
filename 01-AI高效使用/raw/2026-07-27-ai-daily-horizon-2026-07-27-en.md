## [PDF Introduces Data-Oriented Design Principles](https://www.gamedevs.org/uploads/introduction-to-data-oriented-design.pdf) ⭐️ 8.0/10

A PDF presentation by Mike Acton introduces Data-Oriented Design \(DoD\), advocating for designing algorithms by first defining the data layout to optimize CPU cache usage and performance. This paradigm is crucial for performance-critical software like game engines and systems programming, as it directly addresses cache efficiency and memory access patterns, leading to significant speed improvements. The PDF, hosted on gamedevs.org, has a high engagement score of 160 and 41 comments, indicating strong community interest in Data-Oriented Design for performance optimization.

hackernews · tosh · Jul 26, 18:11 · [Discussion](https://news.ycombinator.com/item?id=49060724)

**Background**: Data-Oriented Design is an optimization approach that focuses on how data is laid out in memory and how it is transformed, prioritizing efficient CPU cache utilization. It contrasts with object-oriented design, which often scatters related data across the heap. This technique is widely used in game development to achieve high frame rates and smooth performance.

A new analysis on Vectoral reveals that a relay market for AI tokens is enabling resellers and fraudsters to arbitrage pricing, with sophisticated actors exploiting billing systems and stolen accounts to sell discounted inference. This issue threatens the economics of AI/ML platforms, as token fraud and reselling undercut pricing models and give unfair competitive advantages to businesses that exploit free credits or stolen tokens. It also points to broader systemic flaws in subscription and credit-based economies. The relay market operates similarly to ad fraud markets, using compromised accounts and stolen financial instruments to obtain tokens at below-market rates. Free cloud credits from AWS, Azure, and others are a common source of cheap tokens, with some resellers achieving prices as low as 4% of actual cost.

These markets exploit pricing discrepancies, promotional credits, and billing vulnerabilities to offer discounted access. Unlike blockchain-based relay tokens \(which are automated market makers\), these relays are human-driven arbitrage networks that profit from token resale.

## [Relay Market for Discounted LLM Tokens Reveals Fraud Ecosystem](https://simonwillison.net/2026/Jul/26/relay-market/#atom-everything) ⭐️ 8.0/10

An investigation by Matt Lenhard reveals a thriving market where LLM tokens are resold at a discount through pooled API keys, exploiting free trials, stolen credentials, and chargeback attacks. This ecosystem undermines API security and distorts AI economics, posing financial risks to LLM providers and raising concerns for developers deploying AI applications. Resellers primarily operate in China, using open-source proxy software like one-api and new-api to pool credentials and offer cheaper access, often bypassing geo-restrictions.

rss · Simon Willison · Jul 26, 19:30

**Background**: LLM API providers like OpenAI and Anthropic charge per-token usage fees. The relay market exploits these pricing models by pooling multiple API keys—some obtained through free trial abuse, others stolen—and offering them via proxy servers that load-balance requests. This practice is facilitated by open-source projects such as one-api and new-api, which are legitimate API gateways but can be misused for fraudulent purposes.
