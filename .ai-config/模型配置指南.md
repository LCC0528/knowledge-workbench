# 🤖 AI 模型切换配置指南

本知识库支持多种 AI 助手协作。以下是各模型的使用方式和切换方法。

---

## 方案一：Trae IDE（当前默认，推荐）

**工作方式**：在 Trae IDE 中打开本知识库文件夹，直接对 AI 说指令即可。

**优势**：
- 直接读写 Markdown 文件，无需插件
- 支持复杂多步任务（整理、蒸馏、链接补全）
- 实时编辑，所见即所得

**使用方法**：
1. 用 Trae IDE 打开 `c:\Users\李超超\Desktop\知识` 文件夹
2. 对 AI 说："帮我整理 01-AI高效使用/raw/ 里的资料"
3. AI 会自动读取、处理、生成知识页

---

## 方案二：DeepSeek（通过 Obsidian 插件）

**工作方式**：在 Obsidian 中安装支持 DeepSeek 的插件，在笔记内直接对话。

### 配置步骤

1. **安装插件**：Obsidian → 设置 → 第三方插件 → 关闭安全模式 → 浏览 → 搜索 **Copilot for Obsidian** → 安装并启用

2. **获取 API Key**：
   - 访问 https://platform.deepseek.com/
   - 注册并创建 API Key

3. **配置插件**：
   - 打开 Copilot 插件设置
   - 添加自定义模型提供商（Custom Provider）
   - 填入以下信息：
     ```
     Provider Name: DeepSeek
     Base URL: https://api.deepseek.com/v1
     API Key: 你的DeepSeek API Key
     Model: deepseek-chat
     ```
   - 保存并设为默认模型

4. **使用**：在 Obsidian 中打开命令面板 → 输入 `Copilot: Chat` → 开始对话

### 备选插件

| 插件名 | 特点 | 推荐场景 |
|--------|------|----------|
| **Copilot for Obsidian** | 支持多模型、Vault QA | 日常问答、知识检索 |
| **Text Generator** | 支持模板生成 | 批量生成笔记 |
| **Smart Connections** | 自动关联相似笔记 | 发现知识关联 |
| **Claudian** | 原生支持多 Provider | 想要类 Codex 体验 |

---

## 方案三：多模型混用

不同任务用不同模型，效率最高：

| 任务类型 | 推荐模型 | 原因 |
|----------|----------|------|
| 复杂整理、多步任务 | Trae IDE | 能力强，可直接操作文件 |
| 日常问答、快速检索 | DeepSeek | 便宜、快、中文好 |
| 代码相关（Unity/C#） | DeepSeek-Coder | 代码能力强 |
| 长文档总结 | DeepSeek | 上下文长（64K） |

---

## 方案四：本地模型（离线使用）

**适合**：不想花钱、注重隐私、网络不稳定

### 使用 Ollama + DeepSeek

1. 安装 [Ollama](https://ollama.com/download)
2. 拉取模型：
   ```powershell
   ollama pull deepseek-r1:8b
   ```
3. 在 Obsidian Copilot 插件中配置：
   ```
   Provider Name: Ollama (Local)
   Base URL: http://localhost:11434/v1
   API Key: ollama
   Model: deepseek-r1:8b
   ```

---

## 切换流程总结

```
想用 Trae IDE → 直接在 IDE 里对话（无需配置）
想用 DeepSeek → Obsidian 装 Copilot 插件 → 配置 API Key
想用本地模型 → 装 Ollama → 拉取模型 → 配置插件
想混用       → 不同任务切换不同插件/工具
```

> 💡 **提示**：无论用哪个模型，AI 都应遵循 [AGENTS.md](../AGENTS.md) 中的工作规范。
