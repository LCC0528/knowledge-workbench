# Unity 中级学习路径

## 一、动画系统（Animation System）

### 核心概念
- **Animation Clip**: 单个动画片段（位移、旋转、缩放、属性）
- **Animator Controller**: 状态机，管理 Clip 切换
- **Animator Parameters**: Float/Int/Bool/Trigger 驱动状态转换
- **Blend Tree**: 平滑混合多个动画（如根据速度混合走/跑）
- **Layers & Masks**: 身体分层动画（如上半身射击+下半身走路）
- **IK (Inverse Kinematics)**: 手脚自动贴合地面/物体
- **Root Motion**: 用动画本身驱动角色位移而非代码

### 资源推荐
- [Unity Learn - Animator 基础](https://learn.unity.com/tutorial/animator)
- [Brackeys - 动画系统教程 (YouTube)](https://www.youtube.com/watch?v=hkaysu1Z3CQ)
- [Unity 官方文档 - Animation](https://docs.unity3d.com/Manual/AnimationSection.html)

## 二、UI 系统（UGUI）

### 核心概念
- **Canvas**: 渲染模式（Screen Overlay / Screen Camera / World Space）
- **RectTransform**: anchor / pivot / offset 定位体系
- **UI 组件**: Text (TMP) / Image / Button / Slider / Toggle / InputField / ScrollRect
- **Layout Group**: Horizontal / Vertical / Grid 自动布局
- **Event System**: 点击 / 拖拽 / 悬停事件处理
- **响应式 UI**: 不同分辨率适配策略

### 资源推荐
- [Unity Learn - UGUI 基础](https://learn.unity.com/tutorial/ui-components)
- [Game Dev Guide - 响应式 UI](https://www.youtube.com/watch?v=AGsMUVS0hRg)
- [Unity 官方文档 - UI](https://docs.unity3d.com/Manual/UISystem.html)

## 三、性能优化（Performance Optimization）

### 核心概念
- **Draw Call 与 Batch**: 静态批处理 / 动态批处理 / GPU Instancing
- **LOD (Level of Detail)**: 距离分级显示不同精度模型
- **Occlusion Culling**: 遮挡剔除不可见物体
- **Lightmap 与烘焙**: 静态光照预计算
- **Profiler 使用**: CPU / GPU / Memory / Rendering 分析
- **内存管理**: AssetBundle 加载卸载、对象池 Object Pool
- **Shader 优化**: 简化计算、减少变体

### 资源推荐
- [Unity 官方优化手册](https://docs.unity3d.com/Manual/OptimizationOverview.html)
- [Unity - 优化图形渲染](https://learn.unity.com/tutorial/optimizing-graphics)
- [Coco Code - 对象池模式](https://www.youtube.com/watch?v=n0Rl9s8XmHo)

## 四、底层架构（Architecture & Patterns）

### 核心概念
- **Scriptable Object**: 数据容器、事件系统、配置驱动开发
- **事件驱动架构**: C# Event / UnityEvent / 消息系统
- **状态机模式**: FSM (Finite State Machine) 管理角色/敌人逻辑
- **对象池模式**: 减少频繁 Instantiate/Destroy
- **ECS (Entity Component System)**: Unity DOTS 高性能架构
- **依赖注入**: Zenject / VContainer / 手动 DI
- **Addressables**: 资源远程加载与管理

### 资源推荐
- [Unity - Scriptable Object 教程](https://www.youtube.com/watch?v=aPXvoWVabPY)
- [Game Programming Patterns (中文)](https://gpp.tkchu.me/)
- [Unity DOTS 官方文档](https://docs.unity3d.com/DOTS/)

## 学习建议路线
1. **先 UI + 动画**（可视化反馈强，成就感快）
2. **再架构**（配合 UI/动画项目重构，理解设计模式）
3. **最后优化**（有项目后才有优化场景）
