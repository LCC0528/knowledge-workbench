## 关键内容

### 动画系统核心
- Animator Controller 状态机架构
- Animation Clip 导入与设置
- 代码控制动画播放（GetComponent<Animator>().Play/SetTrigger/SetFloat）
- 模型导入的 Rig / Animation 选项卡设置

### 混合树（Blend Tree）
- 1D 混合（如速度 -> 走/跑）
- 2D 混合（如方向+速度 -> 全方位移动）
- 直接混合（Direct Blend）

### IK 动画
- 设置 IK Pass
- SetIKPosition / SetIKRotation
- 手脚贴合地形/物体

### 动画重定向（Retargeting）
- 同一套动画复用到不同角色
- 依赖 Avatar 和 Humanoid 骨骼映射

### 寻路系统（Navigation）
- NavMesh 烘焙
- NavMeshAgent 组件
- 动态障碍物 NavMeshObstacle
