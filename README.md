# 📚 自生长知识库

基于 Karpathy「自生长」理论搭建的个人知识库，覆盖 **AI高效使用、Unity学习、英语学习** 三个领域。

## 快速开始

### 1. 用 Obsidian 打开知识库

1. 下载安装 [Obsidian](https://obsidian.md/)
2. 打开 Obsidian → 「打开文件夹作为仓库」→ 选择 `c:\Users\李超超\Desktop\知识`
3. 信任作者，即可看到知识库首页

### 2. 用 AI 管理知识库

**方式一：Trae IDE（推荐，你现在正在用的）**
- 直接在这个 IDE 里对 AI 说话
- 例如："帮我把这份资料整理到 AI高效使用 领域"

**方式二：DeepSeek / 其他模型**
- 详见 [.ai-config/模型配置指南.md](.ai-config/模型配置指南.md)

### 3. 开始使用

| 你想做什么 | 怎么做 |
|-----------|--------|
| 存入新资料 | 把资料放进对应领域的 `raw/` 文件夹，告诉 AI 整理 |
| 查看知识 | 打开 `00-首页.md`，从导航进入各领域 |
| 让 AI 整理 | 对 AI 说："整理 XX 领域的 raw 文件夹" |
| 产出内容 | 对 AI 说："基于知识库帮我写一份 XX" |
| 知识复盘 | 对 AI 说："检查 XX 领域，去重补链接" |

## 自生长循环

```
原始资料 → AI整理 → 知识沉淀 → 输出成果 → 回流更新
  raw/      wiki/    skills/     output/      ↺
```

1. **输入**：把网页、文章、视频转录等放进 `raw/`
2. **整理**：AI 读取原始资料，提炼概念，生成知识页放入 `wiki/`
3. **沉淀**：可复用的方法提取到 `skills/`
4. **输出**：基于知识库产出文档、笔记等放入 `output/`
5. **回流**：输出成果反哺知识库，AI 定期复盘更新
